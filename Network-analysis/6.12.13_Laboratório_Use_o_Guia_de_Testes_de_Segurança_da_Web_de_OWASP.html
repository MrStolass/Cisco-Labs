Cenário / de fundo

A fundação sem fins lucrativos Open Worldwide Application Security Project (OWASP) desenvolveu o Web Security Testing Guide (WSTG) para testar os problemas mais comuns de segurança de aplicativos web. O guia é útil para diversas partes interessadas, como desenvolvedores, testadores de software, especialistas em segurança e gerentes de projetos. O Guia de Testes de Segurança da Web OWASP é uma ferramenta gratuita disponível para organizações e indivíduos.

O guia de testes também é uma ferramenta útil para profissionais de segurança ética. Os hackers éticos podem usar o guia para testar as aplicações Web em execução de seus clientes em busca de vulnerabilidades comuns de segurança.

Neste laboratório, você revisará o WSTG e fará uma varredura em um aplicativo Web em busca de vulnerabilidades usando o OWASP Zed Attack Proxy (ZAP). Você investigará algumas das vulnerabilidades que foram descobertas e referenciará uma delas de volta ao WSTG.

Parte 2: Escaneie um site e investigue referências de vulnerabilidade

Nesta parte do laboratório, você realizará uma verificação de vulnerabilidade usando o Zed Attack Proxy (ZAP). Seu alvo é um site intencionalmente vulnerável que está disponível em sua VM. Em seguida, você usará o WSTG para saber mais sobre uma vulnerabilidade que você descobriu.

Etapa 1: Abra o ZAP e iniciar uma varredura.

  1. Inicie a VM Kali conforme necessário. Vá até o menu Kali. Procure por zap e inicie o scanner Zap OWASP.
  2. Clique no botão de rádio superior para persistir a sessão. Isso significa que você pode voltar para a sessão mais tarde.
  3. Feche a janela de diálogo Gerenciar Complementos.
  4. Na janela principal do ZAP, clique na Verificação Automática para iniciar uma verificação.
  5. No campo URL para Ataque, digite 172.17.0.2/dvwa.
  6. Clique no botão Ataque para iniciar a verificação. A verificação deverá levar menos de 10 minutos para ser concluída.

Primeiro, o ZAP usa um rastreador para rastrear a URL e identificar os recursos disponíveis. Em seguida, ela aplicará verificações de vulnerabilidade a cada recurso.

Etapa 2: Investigue os resultados.

  1. Selecione a guia Alertas, se ela ainda não estiver selecionada. Quando a verificação terminar, você será automaticamente transferido para lá.
Quantos alertas foram retornados?
Answer Area
As respostas podem variar, mas o número deve estar em torno de 13 quando a verificação estiver totalmente concluída.

  1. Localize e clique no alerta de Execução de Código Remoto – CVE-2012-1823. Role pelos detalhes do alerta.
Qual é a fonte dessa vulnerabilidade?
Answer Area
Uma versão de PHP desatualizada
Como essa vulnerabilidade pode ser explorada?
Answer Area
O código PHP pode ser injetado em uma string de consulta PHP. Esse código pode ser executado no exec do PHP.

  1. Role para baixo até a seção Marcas de alerta da vulnerabilidade. Observe a chave WSTG e o valor. Clique no valor e use as teclas Ctrl-C para copiar a URL na área de transferência.
  2. Abra o navegador e cole a URL na barra de endereços. Navegue até o site do WSTG e leia sobre a vulnerabilidade e os métodos de teste para ela. Revise essas informações sobre a vulnerabilidade para entender o que o WSTG oferece ao testador de penetração.

Perguntas de Reflexão
1. De quais formas o Guia de Teste de Segurança da Web da OWASP pode ajudar as organizações a proteger suas aplicações?
Answer Area
As respostas variarão, mas podem incluir: identificar etapas para criar e operar um programa de teste de aplicativos Web, determinar lacunas entre as práticas existentes e as melhores práticas do setor, garantir que o software seja codificado de modo seguro e eficiente, tomar decisões informadas sobre quais atividades de segurança e ferramentas investir.
2. Ao realizar um teste de penetração nos aplicativos da Web de um cliente, como você poderia usar o WSTG como guia?
Answer Area
O WSTG oferece diretrizes para 10 tipos de testes que poderiam ser conduzidos em um teste de penetração. Cada tipo de teste possui vários testes específicos com explicações, instruções e exemplos para usá-los, incluindo listas de ferramentas úteis para empregar.
