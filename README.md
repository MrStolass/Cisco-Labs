## 🛠️ Laboratórios em Destaque

### 1. Análise de Quadros Ethernet II com Wireshark (Lab 8.2.8)
Análise profunda do encapsulamento de dados na Camada 2 e 3 do modelo OSI.

* **Ferramentas:** Wireshark, Mininet (CyberOps Workstation VM).
* **Atividades:** Mapeamento MAC/IP, inspeção de pacotes ICMP/ARP e análise de campos de cabeçalho.
* **Valor de Segurança:** A compreensão do ARP é essencial para identificar vetores de ataques **Man-in-the-Middle (MitM)**, como o ARP Spoofing.
* **Resultados:** Identificação do comportamento *hop-by-hop* e validação de tráfego local vs. remoto.
